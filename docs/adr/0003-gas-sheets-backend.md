# หลังบ้านเป็น Google Apps Script + Google Sheets

แอปนี้ใช้กันในครัวเรือนแค่ 2–3 คน จึงใช้ Google Apps Script Web App เป็น API และใช้ Google Sheets เป็นที่เก็บข้อมูล แทน Supabase เพราะฟรี ผู้พัฒนาคุ้นมือ และเปิดดูข้อมูลใน Sheets ได้ตรงๆ GAS ทำหน้าที่เก็บข้อมูลอย่างเดียว ส่วนการคำนวณยอดเหลือใช้และกระปุกทำในเครื่อง การซิงก์ใช้วิธีดึงข้อมูลส่วนต่างตามเวลาแก้ไขล่าสุด และการลบใช้วิธีติดป้ายว่าลบแล้ว

## Consequences

- ไม่มีซิงก์ realtime รายการที่อีกฝ่ายจดจะขึ้นตอนเปิดแอป ตอนดึงรีเฟรช หรือทุก 30 วินาทีขณะเปิดแอปอยู่
- ไม่มีการกำหนดสิทธิ์ในระดับฐานข้อมูล GAS ต้องตรวจ Google ID token และรายชื่ออีเมลของครัวเรือนในทุกคำขอ แล้วตรวจสิทธิ์สมาชิกของกระเป๋าเองในโค้ด
- เจ้าของ Spreadsheet เปิดดูข้อมูลได้ทุกแถว รวมถึงกระเป๋าที่ไม่ได้แชร์ของสมาชิกคนอื่น ความเป็นส่วนตัวมีแค่ระดับในแอป ซึ่งสมาชิกครัวเรือนตกลงกันแล้ว
- ถ้าวันหนึ่งจะเปิดให้คนนอกครัวเรือนใช้ ต้องย้ายหลังบ้านใหม่
